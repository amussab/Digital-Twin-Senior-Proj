Bearing stiffness from shaft displacement: live rig

Finite-element digital twin of the team's Bently Nevada RK4 rig: two 800 g disks, S6700 bearings in PLA rings. Geometry measured on the rig on 16 Nov 2026. The model takes the PROX 1 and PROX 3 readings sent by the edge node and finds the bearing stiffness K, then reports how far K has dropped from the healthy bearing.

Formulation

Method
Finite element method (FEM), 1D beam model of the shaft
Element type
Euler–Bernoulli beam elements (bending only, shear ignored)
Mesh
Elements of 10 mm or less, a node at every bearing, probe and disk and at mid-span, 2 degrees of freedom per node (deflection and slope)
Shaft
Steel, E = 200 GPa, ρ = 7850 kg/m³, diameter 9.9 mm, 550 mm long, bearings at 20 and 530 mm (span 510 mm), 20 mm overhang past each bearing
Bearings
S6700 deep-groove ball bearings (10 × 15 × 4 mm) in PLA rings, as linear springs of stiffness K
Disks
Two 800 g disks (75 mm diameter, 25.5 mm wide) at 190 and 355 mm, as point masses with diametral inertia
Load
Unbalance force F = m·e·ω², shared equally by the two disks
Equation solved
[K(1 + iη) − ω²M]·x = F, η = shaft loss factor (damping)
Live input
Per 20-turn window from the node: Keyphasor speed and the 1X amplitude and phase of PROX 1 and PROX 3
Baseline
With the healthy bearing, the unknown rig unbalance m·e is set so the model matches the probes at the Hertz stiffness K₀
Identification
Each new window: try 1,200 values of K, keep the one whose predicted reading matches the probes. Stiffness loss = (K₀ − K)/K₀
Physics RUL
Fit a straight line to ln(K/K₀) against time over the last 200 windows and extend it to the failure point (25% stiffness drop). RUL = time from now to that point (hand calculation D)
Check
Rigid bearings + 10 N at mid-span reproduces PL³/48EI

Assumptions

  1. Bearings are linear springs. Damping is a small shaft loss factor η = 0.02 (assumed; fit it from a run-up).
  2. The rig's unbalance is not known; it is found once from the healthy baseline and then held fixed.
  3. One K for both bearings (their loads differ by under 2%).
  4. Probe readings are the 1X response, with phase from the Keyphasor. Shaft runout can be removed with a slow-roll reading.
  5. The flexible coupling carries no load; the shaft overhang past each bearing is included.
  6. Probe scale 200 mV/mil (127 µm/V), node divider 0.170, as set in the node firmware.
  7. Healthy stiffness K₀ from a Hertz contact calculation for the S6700 (hand calculation B), in series with the PLA ring (from the CAD file adapter_6f.step). A calculation, not a measurement.

How the model finds K

It tries 1,200 stiffness values. For each one it predicts the probe readings, compares them with the measurement, and keeps the value with the smallest mismatch. Shows the last live window once a baseline is set, otherwise the simulated test.

D. Physics RUL from K

Each live window gives a stiffness K at time t (hours since the baseline). Over the last 200 windows:

y = ln(K/K₀)    fit y = a + b·t by least squares    b = Σ(t − t̄)(y − ȳ) / Σ(t − t̄)²
Failure when K has dropped by the failure fraction f (25%): yfail = ln(1 − f) = ln(0.75) = −0.288
Time of failure tf = t̄ + (yfail − ȳ)/b,   RUL = tf − tnow
Range: repeat with b ± 1.96·se(b), se(b) = √(Σ residual² / (n − 2) / Σ(t − t̄)²)
No RUL is given until there are 8 windows and the line is clearly going down (b + 1.96·se(b) < 0). A healthy bearing gives no RUL.

C. Probe noise

Worst published eddy-current sensor resolution: 3 µm (Sensors, MDPI, 2022). Samples in one 20-revolution window at 1750 rpm and 25 kS/s:

N=fs twindow=25,000×20×601750=17,143N = f_s\,t_{window} = 25{,}000 \times \frac{20 \times 60}{1750} = 17{,}143
σ1×=σraw2N=3 μm×217,143=0.032 μm\sigma_{1\times} = \sigma_{raw}\sqrt{\frac{2}{N}} = 3\ \mu\text{m}\times\sqrt{\frac{2}{17{,}143}} = 0.032\ \mu\text{m}

The demo uses 0.2 µm per window, about 6 times larger, then averages 50 windows and 2 probes:

σavg=0.2 μm50×2=0.020 μm\sigma_{avg} = \frac{0.2\ \mu\text{m}}{\sqrt{50 \times 2}} = 0.020\ \mu\text{m}
