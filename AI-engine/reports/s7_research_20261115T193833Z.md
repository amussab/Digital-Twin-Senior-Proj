## 2. Oracles / floors (hard profile unless stated)

- Clock-only prior (knows TRUE onset time and the generating life distribution, sees no feature): S7-like 70 % (life sigma .35) -> 8 % (sigma .03). The features are doing the work: the model (20 %) is far below the clock prior (70 %).
- Model + oracle true-onset clock feature: 19.98 %; + causal detected-onset clock: 20.10 % -> giving trees the elapsed time does NOT help; a longer-memory/state path is not the bottleneck.
- Two-stage 'progress u_hat then RUL = elapsed (1-u)/u': direct 29.8 %, trees on [features, u_hat, log e, log est] 21.1 %; u_hat MAE is 0.039 but RUL relative error amplifies it by 1/(1-u): the metric's resolution requirement, not a modelling bug.
- Feature (window) noise: ablate real within-run window variation (log-shrink around the run median): x0.5 -> 19.74 %, x0 -> 17.87 % (vs 20.34 %): window noise is worth only ~2.5 points; the rest is per-unit unobservables (life/rate, shape, late-amplification scale, anchor placement).
- Everything unobservable switched off (floor probe: life sigma .03, fixed shape, late sigma .02, jitter 0, 240 train units): 6.56 %. This is where the recipe floor sits: the 20 % is NOT recipe capacity or feature noise, it is per-unit variation the generator draws and nothing in the features can reveal.

## 5. Generator defects looked for

- RUL labels: rul = life - t with life = t_last (run-in included), u = (i - n_h)/(n_d - 1): consistent, no unit/cadence error found (cadence .1667 h, windows <-> hours conversions checked in the S7 frame).
- Anchor mechanics: g saturates at the anchor (u .55 / .85), after that only the late-amplification profile (scaled per unit by lognormal late_scale) carries progress; the HI level at a given u therefore depends on shape (a,p), anchor jitter and late_scale simultaneously. This is the major source of per-unit unobservable variation (not a defect, an assumption: it was chosen wide and test even wider).
- No bug found. The v6 'oracle floor 11.8 %' (their definition, privileged features) is consistent with the 11.6 % reached here when per-unit nuisances are narrowed.

## 6. Conclusion for phase 2

S7 <= 15 % on this generator is reachable only if the per-unit variation (life sigma AND late scale / anchor jitter / shape) is narrow enough that the trend reveals the rate. That is an ASSUMPTION about wear-out variability of the rig bearings; no measurement exists. Phase 2 therefore (i) pre-declares a profile, (ii) keeps the hard profile as a robustness test of the same frozen heads, (iii) reports this sensitivity curve in the final report.
